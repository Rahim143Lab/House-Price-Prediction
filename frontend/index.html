03 — About the model

How the estimate is produced

  1. You describe the property using the form above — size, age, condition, location and a few other details.
  2. The inputs are validated against sensible real-world ranges before anything is sent to the model.
  3. Features are engineered: property age, years since renovation, total bathrooms, room ratios and more are computed from your raw answers.
  4. A trained regression model receives the processed features and estimates a sale price based on patterns learned from historical sales.
  5. The result is returned along with the model used and an approximate error band, so you know how much to trust it.

Regression, in plain terms, means teaching a model to draw the relationship between a set of inputs (like square footage or number of bathrooms) and a continuous number (the sale price) — rather than a category. The model in this project was trained on the Ames Housing dataset (De Cock, 2011), a widely used collection of 2,930 real residential sales in Ames, Iowa, with dozens of recorded property characteristics.
